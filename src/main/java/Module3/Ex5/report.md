## 1. mvn clean

Назначение: Очистка проекта от файлов предыдущих сборок
Создаваемые/удаляемые файлы:

    Удаляет всю папку target/

    Удаляет скомпилированные .class файлы

    Удаляет созданные JAR/WAR архивы

    Удаляет отчеты о тестах и документацию

Результат: Проект возвращается в исходное состояние, как после клонирования из репозитория
## 2. mvn compile

Назначение: Компиляция исходного кода
Создаваемые файлы:

    В папке target/classes/ создаются .class файлы

    Компилируются только файлы из src/main/java/

    Тестовый код (src/test/java/) не компилируется

Результат: Исходный код превращен в байт-код, готовый к выполнению JVM
## 3. mvn test

Назначение: Запуск модульных тестов
Создаваемые файлы:

    В target/test-classes/ - скомпилированные тесты

    В target/surefire-reports/ - отчеты о выполнении тестов

    Файлы формата .txt и .xml с детальной информацией о каждом тесте

Результат: Отчет о прохождении/провале тестов, статистика покрытия
## 4. mvn package

Назначение: Создание готового артефакта для распространения
Создаваемые файлы:

    В папке target/ создается JAR/WAR файл с именем проекта и версией

    Файл содержит все скомпилированные классы и ресурсы

    Включает файл MANIFEST.MF с метаинформацией
